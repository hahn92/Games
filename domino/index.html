Dominó

Las 28 fichas del doble seis, siete para cada uno y el resto al pozo. Sale quien tenga el doble más alto.

Toca una ficha para elegirla y luego el extremo por el que quieres encajarla. La ficha se gira sola si el número que casa es el de abajo — sólo se ofrecen los lados donde de verdad entra.

Si no puedes jugar, robas del pozo hasta poder. Con el pozo vacío se pasa, y si se pasan los dos la partida se cierra: gana quien menos puntos tenga en la mano.

Consejos:
Toca una ficha y luego el < o el > para colocarla.
Con teclado: tabula al tablero, flechas para moverte y Enter para elegir.
Las fichas que no casan salen apagadas: no hace falta que las pruebes.
La máquina suelta primero las de más puntos, así que suele quedarse fichas bajas y difíciles de bloquear.
