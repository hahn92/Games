Descifra el Código

Hay una combinación escondida de cuatro colores, y se pueden repetir. Tienes diez intentos para dar con ella.

Cada intento devuelve cuatro marcas: una roja por cada ficha que acierta color y posición, y una blanca por cada una cuyo color está en el código pero en otro sitio. Las marcas no te dicen a qué ficha corresponden — eso es lo que hay que deducir.

Intentos: 0 Quedan: 10 Récord: —
Consejos:
Toca un color de la paleta para colocarlo; toca la fila en curso para borrar.
Con teclado: tabula al tablero, flechas para elegir color, Enter para comprobar.
Empieza con dos colores repetidos: acota mucho más que cuatro distintos.
El récord es el menor número de intentos, así que menos es mejor.
